Upload file

Máy trạm Windows cùng dải 10.28.10.x: bấm nút để mở ngay thư mục \\\\10.28.10.161\\file-upload bằng Windows Explorer.

Lệnh copy vào Windows Run

Bấm copy rồi dán vào Run/PowerShell/CMD để kết nối thư mục file-upload.

net use \\10.28.10.161\file-upload /delete /y
net use \\10.28.10.161\IPC$ /delete /y
net use * /delete /y
net use \\10.28.10.161\file-upload /user:fileupload 123
explorer.exe \\10.28.10.161\file-upload
Chọn một hoặc nhiều file/ảnh để tải lên máy chủ.
